# Aflopende contracten

Een kleine webapp om bij te houden wanneer contracten zoals energie, internet, tv en verzekeringen aflopen en tot wanneer je kunt opzeggen.

- Per contract: soort, einddatum, opzegtermijn, kosten per maand, automatische verlenging
- Berekent de uiterste opzegdatum en kleurt contracten rood, oranje of groen
- Overzicht van de komende 12 maanden
- Export naar CSV (alleen binnen Claude)

Alles staat in één bestand: `index.html`. Opslag gebeurt in de browser (localStorage), er is geen server nodig.

## Gebruiken

Open `index.html` in een browser, of zet de repository op GitHub Pages.
